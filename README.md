Para abrir la parte visual de nuestro codigo primero se debe descargar una extención de VisualStudio (sencillo y rápido)

Pasos:
1. entra a la terminal con "Ctrl + shift + ñ"
2. ingresa "py -m pip install streamlit pillow"
3. luego de la descarga de la extencion: te recomendará si quieres avisos, simplemente pon ENTER
4. para iniciarlo "py -m streamlit run app.py" (importante que estes en el archivo app.py)
5. disfruta.
